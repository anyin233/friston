# 界面原型 v0.1

直接用浏览器打开 [index.html](index.html)。这是一个自包含文件，不需要服务器。顶部条可以切换 7 个页面；勾选“显示 GPUI 组件映射”后，会显示当前页面用到的 GPUI Kit 组件。

修改时编辑 `src/` 下的文件，然后运行 `./build.sh` 重新生成 `index.html`。

## 页面

| 页面 | 要回答的问题 |
| --- | --- |
| 今天 | 下一场会议是什么？一键按预设开始记录；哪些参会者还没有声纹 |
| 日程 | 本周会议；每场会议的记录方式、纪要模板和会前笔记 |
| 会议中（核心页面） | 实时字幕与说话人、会议桌方位图、发言时长、边开会边记的 Obsidian 笔记 |
| 浮窗字幕 | 独立的置顶窗口，可拖动、可穿透点击，只在“会议中”页面出现 |
| 纪要库 | 一个问题同时搜到白板照片、转写、录音片段、录屏片段和笔记 |
| 纪要详情 | 摘要、决定、待办（可跳到出处）、说话人时间线、截图与录屏 |
| 说话人 | 朗读录入声纹、从录音截取声纹、本机麦克风能力 |
| 设置 | 纪要生成顺序（自带密钥 → 本机 ChatGPT → 本地模型）、模型、录制、Obsidian、索引 |

## 设计约定

- **说话人颜色就是身份**：同一个人在字幕色条、会议桌、时间线、待办负责人、搜索结果中都用同一种颜色。胶囊形状只用于人名。
- **两种字体**：界面用 PingFang SC / SF；笔记和纪要是“文档”，用 Songti SC / New York，行距更大。
- **分栏而不是卡片**：工作台用 1px 分隔线划分区域，对应 GPUI 的 Resizable/Dock。
- **红色只表示“正在录制”**：只出现在标题栏的录制计时上。
- 主题色：纸面 `#F4F6FA`、墨色 `#171A33`、分隔线 `#E2E5EE`、强调色 `#3640D8`、字幕舞台 `#141634`；说话人颜色 `#22A39A` `#E3922A` `#9B6BF2` `#EF5D78` `#3F8EF0` `#7FB449`。

图标来自 gpui-kit-assets 自带的 Lucide 图标（ISC 许可），与 GPUI 应用使用同一套。
