# 在线实时语音识别（Streaming ASR）免费额度、限流与定价调研（2026-11）

目标：评估各家在线实时字幕 / 语音转写 API 的**免费额度（按分钟折算）**、**Rate Limit / 并发约束**及**按分钟计价**，为 Friston 在本地 MLX 之外补充低成本或零成本在线实时字幕后端提供选型依据。

> 计价口径说明：所有小时/秒/Token/Neuron 计价均统一折算为**分钟**（`分钟/天`、`分钟/月`、一次性免费总分钟数，以及 `$/分钟` 或 `元/分钟`）。人民币与美元换算仅作参考（按约 7.2 估算）。各云厂商限流与活动政策以控制台实时配额为准。

## 3. 实时会议场景的关键坑点（Rate Limit 与计费陷阱）

1. **双路采集使并发翻倍、免费时长减半**
   Friston 会中同时采集**本地麦克风**与**系统声音（远程参会者）**两路音轨。如果两路同时建立云端流式连接：
   - 并发占用 ×2：Azure F0（限 1 路并发）会直接拒连第二路；Speechmatics Free（2 路）和 ElevenLabs Free（2 路）正好满载，开第二场或重连瞬时冲突。
   - 时长消耗 ×2：若某一轨全程静音却仍保持连接，AssemblyAI 等按“连接打开时长”计费的服务会双倍扣费。**工程上必须用本地 Silero VAD 先行门控**，仅在检测到说话时才建连或发送音频帧，或将无发言权期间的静音帧截断。
2. **伪流式（HTTP 分片）的最小计费粒度陷阱**
   - Groq 对每次请求设 **10 秒最小计费时长**、AWS Transcribe 设 **15 秒最小计费时长**。如果为了追求亚秒级字幕每 2–5 秒发送一次分片，实际配额消耗会放大 **2–5 倍**。
   - **对策**：HTTP 端只适合配合 VAD 在完整停顿切句后上传整句（如本地草稿层先出字、云端 HTTP 校正定稿），不适合高频滑动窗口重传。
3. **数据隐私与使用条款风险**
   - **Google Gemini API Free Tier** 与 **Google Cloud STT V1 免费 60 分钟/月** 明确包含数据留存/人工审阅或模型训练条款；**ElevenLabs Free** 限制不可用于商业用途。
   - 对企业或个人私密会议录音，即使选免费/试用接口，也应优先选择不拿 API 音频做默认训练的条款（或显式提示用户“录音将上传至第三方服务”并保留纯本地 `Qwen3-ASR` 开关）。
4. **LLM 多模态实时流（Gemini Live / OpenAI Realtime）的二次方膨胀**
   - 对话式多模态 Live API 按“每轮对话上下文累积”重新计费（25 token/秒持续叠加），一场 30 分钟会议的上下文和重放会导致迅速撞上 TPM 上限（如 Gemini 250,000 TPM）或天价账单。**实时字幕应使用专用的流式 ASR 端点，而非对话式 Realtime LLM。**

结合本项目现有的本地 `Silero VAD + Zipformer 草稿层 + Qwen3-ASR 1.7B` 架构，如果后续为实时字幕增加“在线流式提供方（可选，用户自带 Key）”：

1. **中文会议主力（极低成本 + 热词兼容）**：**阿里云百炼 `qwen3-asr-flash-realtime`**（或 `paraformer-realtime-v2`）。单价 `¥0.0144–¥0.0198/分钟`、新人 600 分钟免费，且与本地 `Qwen3-ASR` 的语言提示和术语表理念完全一致。
2. **零成本日常保底（免费额度最高、开箱可用）**：
   - 仅用单路或本地混流后的单流：先消耗 **Azure AI Speech F0（每月 300 分钟永久免费）**，配额用尽后切换 **Cloudflare Workers AI `@cf/deepgram/nova-3`（每天 ~21 分钟永久免费）**；

3. **多语种 / 跨国混合会议低成本方案**：**Soniox Realtime**（`$0.0017–$0.0020/分钟`）或 **AssemblyAI Universal-Streaming**（`$0.0025/分钟`，配合 VAD 静音不发送以防空耗）。
4. **架构保持**：保留本地 `Qwen3-ASR` 作为默认与完全离线/隐私降级通道；任何在线流式后端均通过本地 `Silero VAD` 抑制纯静音音轨传输，以同时节省双轨并发名额与按秒/按分钟额度。
